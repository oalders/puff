# puff MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working `puff` command that lints Perl files with three
security rules (S001 rand, S002 two-argument open, S003 bareword
filehandles) and fixes them with `--fix --unsafe-fixes`.

**Architecture:** PPI parses each file once. An engine walks the tree and
sends elements to rules; rules record fixes as character-range edits
against the decoded source text. A text-only edit applier resolves
conflicts. The fix loop re-parses until the text stops changing.

**Tech Stack:** Perl 5.36, PPI, App::Cmd, TOML::Tiny, Path::Tiny,
Text::Diff, JSON::PP, Module::Pluggable, Test2::V0.

**Spec:** `docs/superpowers/specs/2026-10-08-puff-design.md`. Read it; the
rule behaviour is specified there in detail and is not repeated here.

## Shared interfaces (all tasks)

```perl
# Puff::Source
my $src = Puff::Source->from_file($path);     # dies on read error
my $src = Puff::Source->from_string($text);   # text = already-decoded chars
$src->text;                 # decoded text, BOM stripped
$src->has_crlf;             # bool
$src->offset_of_location($line, $rowchar);  # 0-based char offset
$src->start_of($elem);      # offset of first token of PPI element
$src->end_of($elem);        # offset just past last token
$src->encode($text);        # bytes in original encoding, BOM restored
$src->write_file($path, $text);            # atomic, keeps mode

# Puff::Edits
my ($new_text, $accepted, $deferred) = Puff::Edits::apply($text, \@fixes);
#   @fixes: [{ edits => [{start, end, text}, ...], key => [$sort_start, $code, $line], id => any }]
#   $accepted/$deferred: arrayrefs of the fix hashes

# Puff::Violation  (plain hash object with accessors)
Puff::Violation->new(rule => $rule, code => 'S002', element => $elem,
    line => 3, column => 5, message => '...', fixable => 1, file => $path);

# Puff::Fix
my $fix = Puff::Fix->new(source => $src);
$fix->replace($elem, $text); $fix->insert_before($elem, $text);
$fix->insert_after($elem, $text); $fix->delete($elem);
$fix->replace_range($start, $end, $text);
$fix->edits;               # arrayref of {start, end, text}

# Puff::Rule
sub code; sub summary; sub explanation; sub applies_to; sub fix_safety; sub options;
sub check ($self, $elem, $doc);          # list of violations
sub fix ($self, $violation, $fix);        # true if fix recorded
$self->violation($elem, message => ..., fixable => 0|1);
$self->option($name);
Puff::Rule->new(options => {...});

# Puff::PPIUtil
is_builtin_call($word)  # bool: PPI::Token::Word used as a function call
call_args($word)        # arrayref of arguments; each an arrayref of significant elements

# Puff::Engine
my $engine = Puff::Engine->new(rules => \@rules, fix_mode => 'none'|'safe'|'unsafe');
my $result = $engine->process_source($src, file => $path);
#   { violations => [...remaining], fixed_count => N, new_text => $text|undef,
#     error => $msg|undef, fixes_skipped => $reason|undef }

# Puff::Runner
my $runner = Puff::Runner->new(config => $config, rules => \@rules);
my $summary = $runner->run(\@paths);   # { results => [ {file, ...result} ], exit_code => 0|1|2 }
```

### Task 2: Puff::Source

**Test file:** `t/source.t`. Cases:
- `from_string("my \$x = 1;\nrand();\n")`: `offset_of_location(2, 1)` is 11.
- UTF-8: a file with bytes for `my $s = "é"; rand();`. `from_file` decodes; the PPI location of `rand` maps to the char offset of `rand` in `text`; `substr($text, $off, 4) eq 'rand'`.
- Heredoc: `print <<EOT;\nhello\nEOT\nrand();\n`. Find the `rand` word in the PPI doc built from `text`; `substr` at `start_of` is `rand`.
- POD and `__END__`: a `rand` before them maps correctly; also `__DATA__`.
- BOM: the file begins `\xEF\xBB\xBF`; `text` doesn't contain U+FEFF; `encode($src->text)` returns the original bytes exactly.
- Latin-1: the bytes `"\xE9"` (invalid UTF-8) decode to `é`, and `encode` round-trips them.
- CRLF: `has_crlf` is true for `"a;\r\nb;\r\n"`.
- `write_file` preserves mode 0755 and writes the encoded text.
- `end_of($elem)` for a multi-token statement equals the start of the following whitespace.

Implementation notes: PPI must be given the same text: `PPI::Document->new(\$src->text)`. The line table comes from the positions of `\n` in `text`. `rowchar` is 1-based. Use `$elem->first_token->location` (call `$doc->index_locations` first) and `$elem->last_token` for `end_of`, adding `length($last->content)`. For a `PPI::Token::HereDoc`, content is the `<<EOT` introducer only; that's fine because `end_of` is only used for ranges that `Puff::Fix` refuses to touch when they contain heredocs.

Note: PPI normalises `\r\n`, so locations don't line up with a CRLF file's text. Engine must not fix CRLF files (spec). `has_crlf` is computed on the decoded text.

- [ ] Write the tests, see them fail, implement, see them pass, commit.

### Task 3: Puff::Edits

**Test file:** `t/edits.t`. Cases, with `$t = "abcdefghij"`:
- One replace `{2,4,'XY'}` gives `abXYefghij`.
- Two fixes that don't overlap are both accepted; they're applied from the end backwards.
- Overlapping replaces `{2,5}` and `{4,6}`: the second is deferred.
- An insert at 3 conflicts with the replace `{2,5}`; an insert at 2 or 5 does not.
- Identical edits in two fixes: both fixes are accepted and the text is inserted once.
- A fix with two edits where one conflicts: the whole fix is deferred, and the other edit isn't applied.
- Two different inserts at the same offset: applied in accepted order (`{3,3,'A'}` then `{3,3,'B'}` gives `abcABdefghij`).
- The order of fixes comes from `key` (`[$start, $code, $line]`), not from input order.

- [ ] Write the tests, see them fail, implement `Puff::Edits::apply`, see them pass, commit.

### Task 5: Puff::PPIUtil

**Test file:** `t/ppiutil.t`, checking the first `open` or `rand` word in each snippet:

| snippet | is_builtin_call | args (as strings joined with `|`) |
|---|---|---|
| `open(FH, "<$f");` | 1 | `FH|"<$f"` |
| `open FH, $f or die;` | 1 | `FH|$f` |
| `open my $fh, '<', $f or die "x";` | 1 | `my $fh|'<'|$f` |
| `open(FH, $f) || die;` | 1 | `FH|$f` |
| `open FH, $f if $x;` | 1 | `FH|$f` |
| `$obj->open(1, 2);` | 0 | — |
| `my %h = (open => 1);` | 0 | — |
| `$h{rand};` | 0 | — |
| `sub rand { }` | 0 | — |
| `my $x = rand(10);` | 1 | `10` |
| `my $x = rand;` | 1 | (empty) |
| `open(FH, join(",", @a));` | 1 | `FH|join(",", @a)` |

Args are split on top-level `,`/`=>`; an argument string is its elements' content joined with a single space (`my $fh`). Without parentheses, stop at `;`, `or`, `and`, `xor`, `not`, `if`, `unless`, `while`, `until`, `for`, `foreach`.

### Task 6: Puff::Suppressions

**Test file:** `t/suppressions.t`
- `my $x = rand(); # puff: ignore S001` suppresses S001 on line 1, not S002.
- `# puff: ignore S001, S002` suppresses both. A prefix `S` suppresses `S003`.
- `# puff: ignore-file S00` suppresses `S001` on every line.
- A bare `# puff: ignore` suppresses nothing and gives back one P001 (line, column).
- A comment inside a string doesn't count (the parser only looks at `PPI::Token::Comment`).

API: `my $s = Puff::Suppressions->new($doc); $s->is_suppressed($code, $line); $s->problems` (an arrayref of `{line, column, message}` for P001).

### Task 8: Puff::Engine

**Test file:** `t/engine.t`, using a test-only rule defined inline
(`T001`: flags the word `foo` and fixes it to `bar`, safe; `T002`: flags
`baz` and fixes it to `qux`, unsafe):
- Lint only: violations sorted by line and column; suppressed ones dropped; P001 included.
- `fix_mode => 'safe'` fixes T001 and leaves T002 reported; `unsafe` fixes both.
- Fix loop: a rule whose fix produces another violation (`foo` becomes `foo2`, which T003 then flags) gets fixed on the next pass.
- Pass cap: a rule that toggles `a` and `b` forever gives an error and `new_text => undef`.
- CRLF text: violations are reported, `fixes_skipped` is set, and nothing is fixed.
- `fix` that dies counts as a decline; the violation is still reported.
- `fixed_count` counts violations that went away because a fix was applied (original count minus remaining, with only fixable codes counted).

### Task 9: test harness and S001

**Files:** `t/lib/PuffTest.pm` (`run_corpus($code)`), `t/rule-S001.t`,
`t/corpus/S001/*`, `lib/Puff/Rule/Security/InsecureRand.pm`.

The harness: for each `t/corpus/$code/*.pl` that isn't `*.fixed.pl`:
1. Lint with only that rule; the reported lines must equal the lines carrying `# expect: CODE`.
2. Fix with `fix_mode => 'unsafe'`. If `NAME.fixed.pl` exists, the new text must equal it exactly; otherwise `new_text` must be undef or equal to the input.
3. Re-lint the fixed text: every remaining violation of that code must have `fixable => 0`.

Corpus files for S001:
- `basic.pl`: `use strict;\nuse warnings;\n\nmy $x = rand(10); # expect: S001\nprint int(rand 5); # expect: S001\n`. Fixed: the `use Math::Random::Secure qw(rand);` line is added after `use warnings;`.
- `no-use.pl`: no `use` lines. The import is inserted before the first top-level statement containing rand.
- `package.pl`: `package Foo;\nuse strict;\nsub roll { rand(6) } # expect: S001\n1;`. The import goes after `use strict;`.
- `use-after-call.pl`: a call comes before a later `use`. The import goes before the statement containing the call, not after the later `use`.
- `two-packages.pl`: declined (no `.fixed.pl`).
- `core-and-srand.pl`: `srand(42); CORE::rand(3);` reported, not fixed.
- `not-calls.pl`: `$o->rand; $h{rand}; (rand => 1); sub rand {}`. No violations.
- `already.pl`: has `use Math::Random::Secure qw(rand);`. No rand violations.

- [ ] Write the harness and corpus, see them fail, implement the rule, see them pass, commit.

### Task 11: S003

**Files:** `lib/Puff/Rule/Security/BarewordFilehandle.pm`,
`t/rule-S003.t`, `t/corpus/S003/*`.

Corpus:
- `basic.pl`: `open(FH, '<', $f) or die; while (<FH>) { print STDOUT $_ } close(FH);`. Fixed: `open(my $fh, ...)`, `<$fh>`, `close($fh)`.
- `print.pl`: `open(OUT, '>', $f); print OUT "x\n"; printf OUT "%s", 1; print {OUT} "y"; close OUT;`. Fixed: `print {$out} "x\n"; printf {$out} ...; print {$out} "y"; close $out;`.
- `name-taken.pl`: `my $in = 1; open(IN, '<', $f); my @l = <IN>; close IN;`. Fixed with `$in_fh`.
- `opendir.pl`: `opendir(DH, $d); my @e = readdir(DH); closedir(DH);`. Fixed with `$dh`.
- Declined (reported, no `.fixed.pl`): an open inside `if (open(FH, ...))`; FH used in another sub; two opens of FH; `*FH` glob use; FH passed to a sub `foo(FH)`; `select(FH)`.
- Not reported: `open(STDOUT, '>', $f)`, `open(my $fh, ...)`, `open($fh, ...)`.
- Combined with S002 (in `t/engine.t` or `t/cli.t`): `open(FH, "<$f"); my @l = <FH>; close FH;` with both rules becomes `open(my $fh, '<', $f); my @l = <$fh>; close $fh;`.

### Task 12: Runner, reporters, CLI

**Files:** `lib/Puff/Runner.pm`, `lib/Puff/Reporter/Text.pm`,
`lib/Puff/Reporter/JSON.pm`, `lib/Puff/CLI.pm`,
`lib/Puff/CLI/Command/{check,rule,rules}.pm`, `bin/puff`, `t/cli.t`.

`t/cli.t` copies a few corpus files into a tempdir and runs
`$^X -Ilib -Ilocal/lib/perl5 bin/puff ...` with `chdir` into the tempdir,
capturing output with `qx` and checking `$?`:
- `check` gives exit 1, lines formatted `file:line:col: CODE message [**]`, and a summary.
- `check --fix` leaves files unchanged, exit 1, and the summary mentions `--unsafe-fixes`.
- `check --diff --unsafe-fixes` prints a unified diff (`---`, `+++`, `@@`), leaves files unchanged, exit 1.
- `check --fix --unsafe-fixes` rewrites files to the `.fixed.pl` contents, then `check` again exits 0 for fully fixable files.
- `check --select S002 --output-format json` gives valid JSON with only S002.
- `rules` lists S001, S002, S003 and P001; `rule S002` prints the explanation; `rule X999` exits 2.
- A `.puff.toml` with `ignore = ["S001"]` is honoured; `--no-config` ignores it; an unknown key gives exit 2.
- `exclude`: a file under `local/` is skipped.
